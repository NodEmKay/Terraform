
# Day-14: AWS HA Web Cluster with ALB — Niche Edition

## 🚀 Project Essence
Spin up a highly-available, load-balanced Apache web cluster on AWS — all in a single, readable main.tf. This is a real-world, production-inspired pattern, distilled for clarity and hands-on learning.

## 🏗️ What’s Inside?
- **Custom VPC**: 192.168.5.0/24
- **Two Public Subnets**: 192.168.5.0/25 (us-east-1a), 192.168.5.128/25 (us-east-1b)
- **Internet Gateway & Route Table**: Full public access
- **Security Group**: SSH (22) & HTTP (80) open (demo default)
- **EC2 x2**: Amazon Linux 2, Apache auto-installed, each in a different AZ
- **Application Load Balancer**: Spans both subnets for true HA
- **Target Group & Listener**: HTTP traffic routed to both web servers
- **Output**: ALB DNS for instant browser access

## 🗂️ Why Just main.tf?
- **Laser Focus**: All logic in one place — perfect for demos, interviews, and rapid prototyping.
- **No Module Overhead**: Zero indirection, maximum transparency.
- **Easy to Fork & Extend**: Modularize later if you wish.

## 🖼️ Architecture
```
  [User/Internet]
        |
   [ALB: web-lb]
      /     \
[EC2-1]   [EC2-2]
   |           |
[SubnetA]  [SubnetB]
      \     /
      [VPC]
```

## 🛠️ Usage
1. **Pre-flight**: Ensure you have an AWS key pair named `web-key` in us-east-1.
2. **Init Terraform**:
   ```bash
   terraform init
   ```
3. **Plan & Apply**:
   ```bash
   terraform plan
   terraform apply
   ```
4. **Get Your ALB DNS**: Terraform will output `load_balancer_dns`.

## ✅ Full Verification Steps
### 1. Web Test
- Open `http://<load_balancer_dns>` in your browser.
- You should see: `Hello from <hostname>` (auto-generated by user_data).
- Refresh a few times — you’ll hit both servers via the ALB.

### 2. SSH Test
- Find both EC2 public IPs in the AWS Console.
- SSH in:
  ```bash
  ssh -i /path/to/web-key.pem ec2-user@<instance_public_ip>
  ```
- Check Apache:
  ```bash
  sudo systemctl status httpd
  cat /var/www/html/index.html
  ```

### 3. AWS Console Checks
- **VPC > Subnets**: Two public subnets, two AZs.
- **EC2 > Instances**: Both running, public IPs assigned.
- **EC2 > Load Balancers**: ALB is active, spans both subnets.
- **EC2 > Target Groups**: Both instances healthy.

### 4. Security Group
- Allows SSH (22) and HTTP (80) from anywhere (for demo — restrict for prod!).

### 5. Cleanup
- Destroy all resources:
  ```bash
  terraform destroy
  ```

## 💡 Pro Tips & Extensions
- Parameterize subnet CIDRs, instance type, or AMI for flexibility.
- Add outputs for EC2 public IPs.
- Add private subnets, NAT, or RDS for a full-stack demo.
- For production: split into modules, restrict security groups, use SSM for SSH.
